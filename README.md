# Shoot 'em Up

Unity ile yaptığım yatay kaydırmalı bir uzay gemisi oyunu. Düşmanları vurup sahnedeki hepsini yok edince bölüm bitiyor.

**Build:** [Google Drive](https://drive.google.com/file/d/1TT-gu1S-sBPh_KcLytLLE6kSOoBmQMcc/view?usp=sharing)

## Kontroller

`WASD` / ok tuşları hareket, `Shift` hızlanma, `Left Ctrl` ateş, `Esc` çıkış.

## Çalıştırma

Unity 2022.3.30f1 ile açıp `Assets/Menu.unity` sahnesinden başlatılabilir.
